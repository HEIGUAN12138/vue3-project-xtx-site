# 02 笔记

> ⚠️ **内容声明：** 本站内容由个人学习笔记与 AI 辅助改写整理，代码与 API 细节请以官方文档和实际运行结果为准。原始课件截图与代码片段版权归原作者所有。

Vue3 电商项目实战笔记。以「小兔鲜」这类典型电商前台为线索，把一个 Vue3 项目从脚手架一路拆到支付完成，每一章都拆成六种材料：专业版、白话版、交互图表、案例分析、练习与自测、进一步学习。

**本地入口**：打开 `index.html`（需要 HTTP 服务，不能直接双击）。

## 项目结构

```

├── index.html              # 单页应用（SPA），网站入口，唯一外部依赖是 marked.js

├── CLAUDE.md               # 项目宪法：新增章节必须满足的硬约束
├── PROMPTS.md              # 六种材料的生成提示词模板（P0/P1/P2/P3）
├── Makefile                # make serve / make check（可选，装了 make 才用）

├── tools/
│   ├── serve.js            # 零依赖静态服务器（node tools/serve.js）

    ├── 學習路線圖.md            # 建议学习顺序（文件名固定，index.html 硬编码）

    ├── <章名>/                  # 每章一个目录，目录名 = README 的 ### 标题
    │   ├── <章名>_專業版.md
```

## index.html 运作方式

`index.html` 是零构建 SPA，启动时 `fetch` 本文件并解析结构：

1. `## 各主题分析` 下的每个 `### 标题` 是一个章节，标题必须与 `src/` 下的目录名逐字相同
2. 每个标题下的 `- [文字](src/章名/文件.md) — 描述` 是一份材料，按出现顺序生成页签
3. 材料类型靠**文件名关键词**识别：`白話`→白话版、`案例分析`→案例分析、`練習與自測`→练习、`進一步學習`→进一步学习、`.html`→交互图表，其余为专业版
4. 站内 `.md` 链接会被自动改写成 hash 跳转（如 `../购物车/购物车_專業版.md` → `#购物车`）
5. 交互图表以 `<iframe>` 嵌入，高度固定 80vh，页面内部自行滚动

**因此新增一章只需要三步**：建目录、放六个文件、在本文件注册。详见 `CLAUDE.md`。

## 本地预览

```bash
node tools/serve.js
```

打开 http://localhost:8000 。换端口：`node tools/serve.js 8080`。

**不能直接双击 `index.html`**：它启动时要 `fetch` 本文件解析主题清单，`file://` 协议会被浏览器的 CORS 策略拦住，页面会一直停在加载态。

没有 Node 时的等价做法：`python -m http.server 8000`。装过 `make` 的话也可以用 `make serve`。

## 验收

```bash
node tools/check.js
```

- `FAIL`：违反 `CLAUDE.md` 的文件契约（文件缺失、链接顺序错、术语总表漏章、图表引用了外部资源等），必须修
- `WARN`：指向尚未生成的章节，批量新增过程中属正常
- 退出码：有 FAIL 时为 1，可直接接进 CI

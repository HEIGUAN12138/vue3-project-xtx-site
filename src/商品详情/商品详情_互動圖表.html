放大镜：位置要夹紧，背景要放大

鼠标移进下面的图。切换「只移动」与「移动 + 放大」，看两个方块里的差别。

实现
当前是正确实现：background-size 放大到 2 倍，再用 background-position 把鼠标位置对齐到方块中心；方块本身被夹在图片范围内。
const s = 2 zoom.style.backgroundSize = (w * s) + 'px ' + (h * s) + 'px' zoom.style.backgroundPosition = (-(mx * s - zw / 2)) + 'px ' + (-(my * s - zh / 2)) + 'px' zoom.style.left = clamp(mx - zw / 2, 0, w - zw) + 'px'

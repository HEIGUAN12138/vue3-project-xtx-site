# 商品详情 · 进一步学习

> 这一章的关键词是「组件拼装」「复用残留」与「交互细节」，清单围绕这三件事组织。

## 官方文档

- [Vue 官方文档：插件](https://cn.vuejs.org/guide/reusability/plugins.html) —— `install` 的签名、`app.use` 的调用时机，第七节依据。难度：入门
- [Vue 官方文档：组件注册](https://cn.vuejs.org/guide/components/registration.html) —— 全局注册与 tree-shaking 的关系，第七节取舍的另一面。难度：入门
- [Vue 官方文档：侦听器](https://cn.vuejs.org/guide/essentials/watchers.html) —— `watch` 重置内部状态的写法，第五节与第八节的依据。难度：入门
- [Vue 官方文档：Props](https://cn.vuejs.org/guide/components/props.html) —— 单向数据流，理解「为什么子组件不能直接改 `list`」。难度：入门
- [MDN：getBoundingClientRect](https://developer.mozilla.org/zh-CN/docs/Web/API/Element/getBoundingClientRect) —— 放大镜坐标换算的基础。难度：进阶
- [MDN：background-size](https://developer.mozilla.org/zh-CN/docs/Web/CSS/background-size) —— 放大镜「真的变大」的关键属性。难度：入门
- [MDN：Element.requestFullscreen](https://developer.mozilla.org/zh-CN/docs/Web/API/Element/requestFullscreen) —— 如果要做「点击看大图」，这是标准入口。难度：进阶

## 书籍

- 《Vue.js 设计与实现》（霍春阳） —— 组件更新与 diff 那一部分，能解释「为什么用 index 作 key 会错位、为什么复用会导致状态残留」。难度：高级
- 《CSS 世界》（张鑫旭） —— 背景图定位与层叠，是放大镜这类「纯 CSS 交互」的基础读物。难度：进阶
- 《交互设计沉思录》（Jon Kolko） —— 讲「可预判的失败」为什么比「事后报错」更伤体验，对应加购按钮的三种状态。难度：进阶

## 课程

- [Vue 官方互动教程](https://cn.vuejs.org/tutorial/) —— 组件、props、事件三节，本章组装页面的基础。难度：入门
- [React 文档：Preserving and Resetting State](https://zh-hans.react.dev/learn/preserving-and-resetting-state) —— 虽然是 React，但把「复用与重置」讲得最清楚，跨框架通用。难度：进阶
- [小兔鲜电商项目实战（本笔记的原稿来源）](../Vue3入门/Vue3入门_專業版.md) —— 详情页的图片预览与 SKU 使用在原稿里有完整代码。难度：进阶

## 视频与播客

- [Vue.js 官方 YouTube 频道](https://www.youtube.com/@vuejs) —— 有关于组件设计与全局注册的分享。难度：进阶
- [Syntax.fm](https://syntax.fm/) —— 讨论过「全局组件该不该用」，与第七节的取舍直接相关。难度：进阶
- [Chrome for Developers](https://www.youtube.com/@ChromeDevs) —— 图片加载与合成层优化的实践视频，配放大镜性能一起看。难度：进阶

## 怎么用这份清单

如果只是想把详情页拼起来，看 Vue 的组件注册与插件两页，再照第七节把注册收进一个文件即可。如果遇到「换商品后页面残留旧数据」，去读 React 那篇讲「保留与重置状态」的文章——它不属于任何框架，却能把这一类 bug 一次讲透。如果想把图片预览做扎实，把 `getBoundingClientRect` 与 `background-size/position` 四个属性连起来推一遍坐标公式，再对照第五节的三行夹紧代码，比抄十份实现更有用。

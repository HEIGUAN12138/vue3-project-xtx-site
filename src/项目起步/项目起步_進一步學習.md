# 项目起步 · 进一步学习

> 这一章涉及的工具链最多，清单按「先配置类文档、再书、再课程、最后视频」排序。

## 官方文档

- [Vite 官方文档（中文）](https://cn.vite.dev/) —— 配置、静态资源、依赖预构建三节与本章一一对应，遇到 `vite.config.js` 的问题先来这里。难度：入门
- [Vite 官方文档：为什么选 Vite](https://cn.vite.dev/guide/why.html) —— 讲清了开发时不打包的原理，是理解「为什么配了别名还要重启」的基础。难度：入门
- [Element Plus 官方文档：快速开始](https://element-plus.org/zh-CN/guide/quickstart.html) —— 按需导入、自动导入的官方配置，照抄即可。难度：入门
- [Element Plus 官方文档：自定义主题](https://element-plus.org/zh-CN/guide/theming.html) —— SCSS 变量与 CSS 变量两条路的取舍讲得很清楚。难度：进阶
- [axios 官方文档（中文）](https://axios-http.com/zh/docs/intro) —— 实例与拦截器两节是本章第五节的直接来源。难度：入门
- [Vue Router 官方文档：入门](https://router.vuejs.org/zh/guide/) —— 嵌套路由与懒加载是第六节的依据。难度：入门
- [Sass 官方文档：@use 与 @forward](https://sass-lang.com/documentation/at-rules/use) —— 解释为什么覆盖变量必须写在文件最前面。难度：进阶

## 书籍

- 《深入浅出 Vite》（吴浩麟等） —— 系统讲了依赖预构建、HMR、插件机制，本章的配置项在书里都能找到原理层解释。难度：进阶
- 《Vue.js 3 企业级应用开发实战》 —— 有完整的工程化章节，覆盖别名、组件库、请求封装三块，适合想看「团队规范怎么定」的读者。难度：进阶

## 课程

- [Vite 官方文档的「开始」章节](https://cn.vite.dev/guide/) —— 严格说不算课程，但按顺序走一遍比看任何视频都扎实。难度：入门
- [Vue 官方互动教程](https://cn.vuejs.org/tutorial/) —— 如果对 `<script setup>` 还不熟，先补这里再回来看构建配置。难度：入门
- [小兔鲜电商项目实战（本笔记的原稿来源）](../Vue3入门/Vue3入门_專業版.md) —— 项目起步的完整过程在原始课件里有逐步截图。难度：进阶

## 视频与播客

- [Vue.js 官方 YouTube 频道](https://www.youtube.com/@vuejs) —— 有 Vite 与工具链相关的分享录像。难度：进阶
- [Vite 与工程化配置讲解（B 站）](https://search.bilibili.com/all?keyword=Vite%20%E9%85%8D%E7%BD%AE) —— 中文讲解，适合看别人从零配一遍建立手感。难度：入门
- [Syntax.fm](https://syntax.fm/) —— 前端工程化话题的讨论，能了解为什么社区从 webpack 转向 bundler-free 开发。难度：进阶

## 怎么用这份清单

如果只是想把这五个配置项配通，看 Vite 与 Element Plus 的官方文档就够了。如果准备长期维护这个构建配置，补上《深入浅出 Vite》，重点是依赖预构建与 HMR 那两章，那能解释掉大部分「改了没生效」的现象。至于主题定制，先按官方文档做一遍 CSS 变量方案，只有在需要改尺寸类令牌时才上 SCSS。

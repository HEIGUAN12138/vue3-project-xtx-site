# 一级分类页 · 进一步学习

> 这一章的关键词是「参数复用的反应」与「竞态」，清单围绕这两件事组织。

## 官方文档

- [Vue Router：动态路由匹配](https://router.vuejs.org/zh/guide/essentials/dynamic-matching.html) —— `:id` 的写法与「组件复用」的官方说明，第六节的全部依据。难度：入门
- [Vue Router：响应路由参数的变化](https://router.vuejs.org/zh/guide/essentials/dynamic-matching.html#%E5%93%8D%E5%BA%94%E8%B7%AF%E7%94%B1%E5%8F%82%E6%95%B0%E7%9A%84%E5%8F%98%E5%8C%96) —— 官方给的 `watch` 示例，可直接对照本章的 `useCategory`。难度：入门
- [Vue Router：导航守卫](https://router.vuejs.org/zh/guide/advanced/navigation-guards.html) —— `onBeforeRouteUpdate` 与全局守卫的区别，理解「为什么它不管首次进入」。难度：进阶
- [Vue 官方文档：侦听器](https://cn.vuejs.org/guide/essentials/watchers.html) —— `immediate`、`deep`、以及「computed 与 watch 的分工」。难度：入门
- [Vue 官方文档：组合式函数](https://cn.vuejs.org/guide/reusability/composables.html) —— 第七节把取数拆成 `useCategory` 的规范依据。难度：进阶
- [MDN：AbortController](https://developer.mozilla.org/zh-CN/docs/Web/API/AbortController) —— 主动取消请求的标准做法，与序号方案对照看。难度：进阶
- [W3C ARIA APG：Breadcrumb Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/) —— 面包屑的标准语义，`nav` 与「最后一层不可点」的出处。难度：进阶

## 书籍

- 《Vue.js 设计与实现》（霍春阳） —— 响应式依赖收集与 `watch` 的实现，能解释「为什么必须在 setup 期间注册副作用」。难度：高级
- 《JavaScript 高级程序设计》（第 4 版） —— Promise 与异步流程控制那几章，是理解乱序响应的基础。难度：进阶
- 《CSS 世界》（张鑫旭） —— 面包屑与列表布局里的行内元素、分隔符实现，属于样式细节的补课。难度：进阶

## 课程

- [Vue Router 官方示例（examples 仓库）](https://github.com/vuejs/router/tree/main/examples) —— 动态参数、嵌套路由、守卫的可运行示例，比读文档更快建立直觉。难度：入门
- [web.dev：网络请求与性能](https://web.dev/learn/performance) —— 理解「为什么要取消无用请求」，为竞态处理提供性能视角。难度：进阶
- [小兔鲜电商项目实战（本笔记的原稿来源）](../Vue3入门/Vue3入门_專業版.md) —— 一级分类页的完整搭建过程在原始课件里有逐步说明。难度：进阶

## 视频与播客

- [Vue.js 官方 YouTube 频道](https://www.youtube.com/@vuejs) —— 有关于 Router 4 与组合式 API 配合的分享。难度：进阶
- [Syntax.fm](https://syntax.fm/) —— 讨论过「前端请求竞态与取消」，对第六节的取舍有参考价值。难度：进阶
- [Chrome for Developers](https://www.youtube.com/@ChromeDevs) —— 讲 `AbortController` 与 Fetch 取消的实践视频。难度：进阶

## 怎么用这份清单

如果只是想让页面跟着参数变，读 Vue Router 的「响应路由参数的变化」那一小节就够，照抄 `watch` 即可。如果偶尔出现「数据串了」，去读 `AbortController` 与本章 Case 4，理解「取消」和「丢弃」是两种不同的解法。如果想把这一页的代码拆干净，把 Vue 的组合式函数一章与 `effectScope` 一节连着读，再对照第七节的 `useCategory`——你会明白为什么「必须在 setup 期间调用」不是一句教条，而是副作用归属的技术约束。

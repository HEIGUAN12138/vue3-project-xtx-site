# 登录页 · 进一步学习

> 这一章的关键词是「校验」「凭证」「跳转」，清单围绕这三件事组织。

## 官方文档

- [Element Plus：Form 表单](https://element-plus.org/zh-CN/component/form.html) —— `rules` 的完整字段、`validate` 的两种调用方式、`validateField` 与 `clearValidate` 的用途。难度：入门
- [Vue Router：导航守卫](https://router.vuejs.org/zh/guide/advanced/navigation-guards.html) —— 全局前置守卫与「未登录被拦下」的标准写法，第二节与第七节的基础。难度：入门
- [Pinia：Plugins](https://pinia.vuejs.org/zh/core-concepts/plugins.html) —— `persist` 是怎么实现的，理解插件如何扩展 store。难度：进阶
- [pinia-plugin-persistedstate](https://prazdevs.github.io/pinia-plugin-persistedstate/zh/) —— `key`、`paths`、`storage` 三个配置项，决定「什么该落地、什么不该」。难度：进阶
- [axios：Interceptors](https://axios-http.com/zh/docs/interceptors) —— 请求/响应拦截器的执行顺序，以及在拦截器里抛错的后果。难度：入门
- [MDN：HTTP 认证](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Authentication) —— `Authorization` 头、`Bearer` 与 `Basic` 的区别，第六节那句 `Bearer` 的出处。难度：进阶
- [OWASP：Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) —— 从服务端视角看登录该防什么，读完会明白前端校验为什么不能当安全边界。难度：高级

## 书籍

- 《Web 应用安全权威指南》（徳丸浩） —— 从会话管理讲到 XSS 与 CSRF，是理解「token 存哪」这件事最系统的一本中文书。难度：进阶
- 《HTTP 权威指南》（David Gourley、Brian Totty 等） —— 状态码、认证头、缓存三章，把 401 与 `Authorization` 放回协议语境里。难度：进阶
- 《Vue.js 设计与实现》（霍春阳） —— 响应式与组件更新部分，能解释「为什么 `userInfo.value = {}` 能触发视图更新，而逐字段赋值要看字段是否被追踪」。难度：高级

## 课程

- [Element Plus 官方文档：快速开始](https://element-plus.org/zh-CN/guide/quickstart.html) —— 含按需引入与自动导入插件的配置，第 3 章配过一遍，这里可以对照。难度：入门
- [Vue 官方互动教程](https://cn.vuejs.org/tutorial/) —— 表单输入绑定那一节，是 `v-model` 与校验联动的前置知识。难度：入门
- [MDN 学习区：表单数据校验](https://developer.mozilla.org/zh-CN/docs/Learn/Forms/Form_validation) —— 原生校验 API 的教程，理解「校验时机」这个概念从哪来。难度：进阶
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) —— 免费的在线实验室，其中「Authentication」与「CSRF」两个专题可以直接动手打一遍。难度：高级

## 视频与播客

- [Vue.js 官方 YouTube 频道](https://www.youtube.com/@vuejs) —— 有关于 Vue Router 与状态管理的官方分享。难度：进阶
- [Syntax.fm](https://syntax.fm/) —— 多期节目讨论过「JWT 到底该不该用」，正反两方都讲了。难度：进阶
- [OWASP 官方 YouTube 频道](https://www.youtube.com/@OWASPGLOBAL) —— 会议录播，关于会话管理与开放重定向的实战分享。难度：高级

## 怎么用这份清单

如果只是想把登录页写完，读 Element Plus 的 Form 与 Vue Router 的守卫两页就够，其余按需查。如果准备上线，先读 OWASP 的 Authentication Cheat Sheet——它不会教你写代码，但会告诉你哪些做法在真实攻击面前等于没做。如果对「token 存哪」这个取舍一直拿不定，去看 Syntax.fm 里关于 JWT 的那几期，两边观点都摆出来了，比任何一篇单方面鼓吹的文章更有用。

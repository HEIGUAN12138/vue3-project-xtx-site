# 术语总表 Glossary

> 本术语总表汇整《02 笔记》14 章中的核心前端与 Vue 生态术语，按学习顺序分章收录，方便查阅。术语与各章专业版保持一致，新增术语请先在此表查重。

---

## 1. Vue3入门 Vue 3 Fundamentals

📖 [前往主题学习](#Vue3入门)

| 术语 | English | 定义 |
|------|---------|------|
| 组合式 API | Composition API | 以函数组合方式组织逻辑的 API 风格，逻辑按功能聚合而非按选项分散 |
| 选项式 API | Options API | 用 data/methods/computed 等选项描述组件的写法，Vue2 的默认风格 |
| setup | setup | 组合式 API 的入口函数，在组件实例创建前执行，返回的绑定暴露给模板 |
| script setup | `<script setup>` | 编译期语法糖，让 setup 内的顶层变量自动暴露给模板，代码量最少 |
| 响应式 | Reactivity | 数据变化后自动触发依赖它的视图或计算重新执行的能力 |
| 响应式代理 | Reactive Proxy | Vue3 用 Proxy 拦截对象读写，从而收集依赖并触发更新 |
| 依赖追踪 | Dependency Tracking | 渲染时记录「谁读了哪个属性」，属性变化时只通知这些读者 |
| ref | ref | 包装基本类型或对象的响应式容器，通过 `.value` 读写 |
| reactive | reactive | 直接返回对象代理的响应式 API，仅适用于对象/数组，解构会丢失响应性 |
| 计算属性 | computed | 由其他响应式数据派生出的缓存值，依赖不变时不重新计算 |
| 侦听器 | watch | 监听指定数据源变化并执行副作用的 API，可拿到新旧值 |
| watchEffect | watchEffect | 自动收集回调内用到的依赖并立即执行一次的侦听 API |
| 生命周期钩子 | Lifecycle Hook | 组件在挂载、更新、卸载等阶段暴露的回调，如 onMounted |
| 单文件组件 | SFC, Single-File Component | 把 template/script/style 写在一个 `.vue` 文件里的组件格式 |
| 模板编译 | Template Compilation | 把模板字符串编译成渲染函数的过程，Vue3 在构建期完成 |
| 虚拟 DOM | Virtual DOM | 用 JS 对象描述真实 DOM 结构，通过 diff 计算最小更新量 |
| 属性 | props | 父组件传给子组件的只读数据，单向数据流 |
| 自定义事件 | emit | 子组件向父组件通知事件的机制，配合 `defineEmits` 声明 |
| 插槽 | slot | 父组件向子组件指定位置插入内容的机制，分默认插槽与具名插槽 |
| 双向绑定 | v-model | 属性 + 事件的语法糖，组件上默认展开为 modelValue 与 update:modelValue |
| 指令 | Directive | 以 `v-` 开头、作用于 DOM 的特殊属性，如 v-if、v-for、v-show |
| 组合式函数 | Composable | 以 `use` 开头、把可复用逻辑封装成函数并返回响应式状态的写法 |
| 解构丢失响应性 | Loss of Reactivity | 直接解构 reactive 对象得到普通值，后续更新不再触发视图 |

## 2. Pinia入门 Pinia Basics

📖 [前往主题学习](#Pinia入门)

| 术语 | English | 定义 |
|------|---------|------|
| 状态管理 | State Management | 把跨组件共享的数据集中存放与修改的模式 |
| store | Store | Pinia 中承载状态、派生值与动作的容器实例 |
| defineStore | defineStore | 定义 store 的函数，支持选项式与组合式两种写法 |
| 状态 | state | store 中的数据源，等价于组件里的 data |
| 派生值 | getters | 基于 state 计算出的只读值，等价于 computed |
| 动作 | actions | 修改 state 的方法，可同步也可异步 |
| 持久化 | Persistence | 把 store 状态写入 localStorage 等介质，刷新后恢复 |
| 订阅 | subscribe | 监听 store 状态变化并执行回调的机制 |

## 3. 项目起步 Project Setup

📖 [前往主题学习](#项目起步)

| 术语 | English | 定义 |
|------|---------|------|
| create-vue | create-vue | Vue 官方脚手架，底层使用 Vite，替代旧版 vue-cli |
| Vite | Vite | 基于原生 ESM 的开发服务器与构建工具，冷启动快 |

| 按需导入 | On-Demand Import | 只打包实际用到的组件，靠 unplugin-vue-components 自动完成 |
| 自动导入 | Auto Import | 自动注入 ref、computed 等 API，省去手写 import |
| Sass | Sass | CSS 预处理器，支持变量、嵌套、mixin，用于定制主题 |
| 主题定制 | Theme Customization | 通过覆盖 Element Plus 的 SCSS 变量改变主色、圆角等外观 |

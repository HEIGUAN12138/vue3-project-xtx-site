# 订单页 · 进一步学习

> 这一章的关键词是「报价与下单」「状态分离」「幂等」，清单围绕这三件事组织。

## 官方文档

- [Vue Router：编程式导航](https://router.vuejs.org/zh/guide/essentials/navigation.html) —— `push`/`replace`、`query`/`params` 的完整差异，第七节的依据。难度：入门
- [Element Plus：Dialog 对话框](https://element-plus.org/zh-CN/component/dialog.html) —— `modelValue` 与 `update:modelValue`、`before-close` 的用法，第四节的基础。难度：入门
- [Element Plus：Form 表单校验](https://element-plus.org/zh-CN/component/form.html) —— 留言框与地址表单需要校验时，规则写法与第 9 章一致。难度：入门
- [MDN：Crypto.randomUUID](https://developer.mozilla.org/zh-CN/docs/Web/API/Crypto/randomUUID) —— 幂等键的生成方式，注意它只在安全上下文可用。难度：进阶
- [MDN：HTTP 请求方法](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Methods) —— 幂等与安全的定义，理解为什么 `POST` 需要额外保护。难度：进阶
- [Stripe：Idempotent requests](https://docs.stripe.com/api/idempotent_requests) —— 幂等键的工业级设计：冲突返回 422、键保留 24 小时。难度：高级

## 书籍

- 《设计数据密集型应用》（Martin Kleppmann） —— 事务与幂等的那一章，把「重复请求」放进分布式系统的语境里看。难度：高级
- 《企业应用架构模式》（Martin Fowler） —— 有一节专门讲「用事务脚本处理订单」，以及为什么下单逻辑不该散在控制器里。难度：进阶
- 《Vue.js 设计与实现》（霍春阳） —— 组件更新与 `key` 的作用，理解第八节「别用 index 作 key」的底层原因。难度：高级

## 课程

- [Vue 官方互动教程](https://cn.vuejs.org/tutorial/) —— 表单绑定与列表渲染两节，是结算页的前置知识。难度：入门
- [MDN 学习区：表单与数据发送](https://developer.mozilla.org/zh-CN/docs/Learn/Forms/Sending_and_retrieving_form_data) —— 理解「提交」这件事在协议层发生了什么。难度：入门
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) —— 「Business logic vulnerabilities」专题，订单与价格篡改是经典题型。难度：高级

## 视频与播客

- [Vue.js 官方 YouTube 频道](https://www.youtube.com/@vuejs) —— 关于路由与状态管理的官方分享。难度：进阶
- [Syntax.fm](https://syntax.fm/) —— 多期节目讨论过「支付与重复提交」，与本节的幂等键直接相关。难度：进阶
- [Stripe Sessions](https://www.youtube.com/@StripeDev) —— 支付工程实践的公开分享，含大量真实踩坑。难度：高级

## 怎么用这份清单

如果只是把结算页写完，Vue Router 与 Element Plus Dialog 两页足够。如果你在做真实交易系统，先读 Stripe 的幂等文档，再回头看本章第六节的三道防线——你会发现工业级实现与教学版本的差距，主要不在代码量，而在「哪些失败必须被当成同一次意图」。想弄清「为什么不能用 index 作 key」，去读《Vue.js 设计与实现》里组件更新的部分，比看十篇博客都直接。最后，业务逻辑漏洞是这类页面最现实的威胁，PortSwigger 的实验室可以当作一次低成本的实战演练。
